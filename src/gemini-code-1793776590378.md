# ROLE & ARCHITECTURAL OBJECTIVE
You are a Staff Frontend Engineer and Design Technologist specializing in building production-grade interactive prototypes.
Your objective is to generate a fully functioning, responsive single-page web application (SPA) emulating a mobile iOS app inside an iPhone 16 Pro viewport shell (393x852px) centered on desktop screens, or full-width on actual mobile devices.
The application is "Schuhwerker 3D – Zeig, wer du bist", a bespoke footwear discovery and customization app designed for 3D-printing makers and design enthusiasts.

# DESIGN SYSTEM: DIETER RAMS FUNCTIONALISM ("WENIGER, ABER BESSER")
- Principles: Absolute functional clarity, mathematical order, zero gratuitous shadows/gradients, high contrast, strict 8px spatial rhythm.
- Color Tokens:
  - Base Background: Pure White (`#FFFFFF`) and Warm Off-White (`#F9FAFB`).
  - Container Borders: Ultra-crisp 1px hairline gray (`#E4E4E7`).
  - Primary Typography: Deep Carbon/Charcoal (`#18181B`).
  - Secondary Metadata / Labels: Technical Gray (`#71717A`).
  - Single Functional Focus Accent: Dieter Rams Signal Safety Orange (`#EA580C`) used solely for active focal states, primary action triggers, and tolerance badges.
  - Verification Accent: Forest Green (`#16A34A` / bg `#DCFCE7`) for passed printability checks.
- Typography: Sans-serif (Inter/SF Pro) for general UI; Monospaced (`font-mono`) for all dimensions, tolerances, and calibration telemetry.

# TECH STACK
- Framework: React 18 + Vite + TypeScript
- Styling: Tailwind CSS
- Icons: `lucide-react`
- 3D Rendering: Three.js (or HTML5 Canvas 3D projection) for interactive rotating models.

# CORE CAPABILITIES & LINEAR STATE MACHINE (6 STEPS)
Implement an interactive State Machine navigating through all 6 MVP phases:

### Step 1: Guided Setup & Hardware Pathing (`onboarding`)
- Header: Minimalist linear progress indicator ("STEP 01 / 06") + "Schuhwerker 3D".
- Checklist Card: 3 items with toggleable state:
  1. Standard credit/reference card ready
  2. Flat, contrasted hard surface
  3. Est. duration: 10–12 minutes.
- Hardware Profile Selector:
  - Segmented toggle: [ "Maker (3D-Drucker vorhanden)" | "Access (Print-on-Demand Partner)" ].
  - If Maker is active: Dropdown for printer type (Bambu Lab X1C/P1S, Prusa MK4, Ender 3).
- Alternative Entry: Option card for "SoleMatch: Clone your Sole" (explaining instant insole measurement shortcut).
- Action: "Messung starten" (advances to Step 2).

### Step 2: LiDAR & Camera Emulation Viewfinder (`scan`)
- Video Feed: Activate live webcam stream via `navigator.mediaDevices.getUserMedia({ video: { facingMode: 'environment' } })`.
  - Fallback: If camera access is blocked or unavailable, automatically fall back to an animated SVG/Canvas wireframe simulation of a foot outline without breaking.
- Overlay: Canvas-based geometric LiDAR mesh overlay displaying:
  - Animated polygon coordinate points scanning across the foot contour.
  - Live technical HUD: `DISTANCE: 32.4 CM • PLANE: HORIZONTAL • LIGHT: OPTIMAL`.
  - Circular progress ring advancing from 0% to 100% over 6 seconds of holding steady.
- Action: Once 100% is reached, trigger an audio/visual snapshot pulse and proceed to Step 3.

### Step 3: Foot Metrics Dashboard & Tolerance Verification (`metrics`)
- Visualizer: Interactive 3D wireframe mesh of the captured foot (click-and-drag to orbit/rotate).
- Precision Data Grid (2x2 Auto-Layout):
  - Foot Length: `284 mm`
  - Forefoot Width: `106 mm`
  - Instep Height: `72 mm`
  - Tolerance Indicator: `±1.5 mm Window` (marked in Safety Orange pill badge).
- Hybrid Cross-Check Card:
  - Status banner with green checkmark: "Hybrid-Check bestätigt: Optischer Scan deckt sich mit physikalischen Referenzwerten (Delta: +1.2 mm)".
- Action: Primary Button "Weiter zum Konfigurator" (advances to Step 4).

### Step 4: Model Selector & 3D Live Customizer (`customizer`)
- Model Selection: Segmented switcher: [ "PureSlide (Flip-Flop)" | "UrbanFlow (Sneaker)" ].
- 3D Viewport: Render an interactive shoe model with drag-to-rotate capability.
- Customization Controls:
  - 3-Zone Palette: Separate color selectors for:
    1. Outsole (Hex choices: Bone White `#F4F4F5`, Stealth Black `#18181B`, Signal Orange `#EA580C`, Olive `#3F3F46`)
    2. Midsole/Upper
    3. Structural Accent.
  - Live Deboss Text Field: Input up to 4 characters (e.g. "TA26") debossed visibly onto the heel of the 3D model.
  - Tread Profile Selector: Radio toggle between "HexaGrip (Wabe)" and "WaveTrail (Lamelle)".
- Action: Primary Button "Druckbarkeit prüfen" (advances to Step 5).

### Step 5: Geometry & Printability Verifier (`printability`)
- Spec Audit against selected printer profile:
  - E.g. "Printer: Bambu Lab X1-Carbon (256x256x256 mm)".
- Automated Test Checkpoints (Clean cards with verified badges):
  - "Wandstärken-Prüfung: Min. 1.8 mm (Bestanden)"
  - "Überhang-Validierung: Max. 52° (Support-frei druckbar)"
  - "Druckbett-Passung: 100% OK (Diagonale 45°-Orientierung aktiviert)".
- Safety Notice: "Material: TPU Shore 85A/95A. 0h Slicer-Aufwand nötig."
- Action: Primary Button "Fertigungsdaten generieren" (advances to Step 6).

### Step 6: Export & Production Hand-off (`export`)
- Header: Minimal checkmark icon + "Dein Schuh ist produktionsbereit".
- Dynamic Hand-off Panels:
  - Panel A (For Makers): Download Card with file icon. Title: "Slicer-Projekt (.3mf / .gcode)". Checklist: "TPU vorab 4-6h getrocknet?". CTA Button: "3MF-Paket herunterladen" (generates and downloads a dummy `.3mf` text bundle file).
  - Panel B (For Non-Makers / Service): Order Card with shipping icon. Title: "Print-on-Demand Fertigung". Pricing: "159,00 € inkl. MwSt.", Delivery: "5–7 Werktage", "100% Passform-Garantie". CTA Button: "Bestellung verbindlich anfragen".
- Action: Secondary link "Zurück zum Dashboard / Neu konfigurieren" (resets state machine to Step 1).
